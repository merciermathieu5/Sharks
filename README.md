# Sharks — interface de DG déplacée

Depuis le 28 novembre 2026, l'interface de DG des Sharks de San Jose fait partie de
l'**interface unique des 32 équipes de la USHL**, dans le dépôt
[ushl-releve](https://github.com/merciermathieu5/ushl-releve) :

https://merciermathieu5.github.io/ushl-releve/?equipe=SANJOSE

La page de ce dépôt redirige vers cette adresse, avec l'équipe déjà choisie.
Les réglages sauvegardés dans le navigateur (matrices, trios, composition,
transactions) sont repris tels quels par l'interface unique.

Les workflows de copie des relevés (production.yml, rosters.yml), les scripts
et les données ont été retirés : l'interface unique lit les relevés centraux
sur place. L'ancienne interface reste dans l'historique de ce dépôt.
